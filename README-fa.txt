اجرای Barcode POS با ارسال خودکار ایمیل
1) Node.js نسخه 18 یا بالاتر لازم است (چیزی نصب نمی‌شود).
2) فایل env.example را به .env تغییر نام دهید و مقدارها را پر کنید (SMTP، SEND_KEY، ALLOWED_RECIPIENTS).
   برای Gmail از «رمز برنامه» (App Password) استفاده کنید، نه رمز اصلی.
3) اجرا:  node server.js   سپس  http://localhost:8080
4) در برنامه: ارسال به کارگزار ← ایمیل و «کلید ارسال» (همان SEND_KEY) را بزنید.
برای نصب روی گوشی، سرور باید پشت HTTPS باشد. فایل .env را جایی منتشر نکنید.
